# Web Plugin

Web development skills covering HTML, CSS, JavaScript, web APIs, security, performance, and accessibility.

## Overview

This plugin provides expert guidance for web development across the full stack of web technologies.

## Install

In Claude Code 2.1.275 or newer:

```text
/plugin install web --marketplace atc-net/atc-agentic-toolkit
```

In GitHub Copilot CLI, or an older Claude Code, add the marketplace first:

```text
/plugin marketplace add atc-net/atc-agentic-toolkit
/plugin install web@atc-agentic-toolkit
```

For VS Code, see the [Quick Start](../../README.md#-quick-start).

## Skills

### web-coder

Comprehensive web development expertise covering HTML, CSS, JavaScript, web APIs, HTTP/HTTPS, security, performance optimization, and accessibility.
